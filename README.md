# Japanese Women's Leadership Initiative (JWLI)



## Project Description

A responsive-style website recreation for the Japanese Women's Leadership Initiative (JWLI), an organization dedicated to empowering Japanese women through leadership development and social change.

The project focuses on recreating a professional, multi-section website with organized content, navigation, images, and a clean user interface.

## Tech Stack

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, and visual design
- **JavaScript** – Front-end scripting

## What I Learned

- Structuring a multi-section website using semantic HTML
- Using CSS Flexbox to organize content and create layouts
- Styling navigation menus, buttons, forms, and images
- Improving visual consistency through spacing, typography, and alignment
- Strengthening my understanding of front-end development

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Semajleona/JWLI.git
   ```

2. Navigate into the project folder:

   ```bash
   cd JWLI
   ```

3. Open `index.html` in your web browser.

No additional dependencies or installation required.
